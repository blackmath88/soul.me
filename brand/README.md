# Brand: the visual north star

[`brand-kit.html`](brand-kit.html) is the visual north star for soul.me (D-019). Open it in a browser;
everything in it is drawn procedurally from seeded rules and pixel grids, with no image files.

## The one rule

**Grey is the world; colour is yours.** Vendors, employers, proposals, processes and the night are drawn
in greys. Colour appears only on what the person has sealed. A line changes colour at one moment: when it
is stamped `[stated]`. Shu red is the seal and nothing else.

## How it maps to the product

| In the kit | In soul.me |
|---|---|
| the fox (kitsune) | `minime.md`, the self |
| masks on the rope, grey | providers: Claude, ChatGPT, Copilot, local models |
| lit screens, grey | places: work, home |
| the stone wall (nurikabe) | the sanitising pass at the employer boundary |
| grey wisps (small obake) | `[imported]` / `[inferred]` lines in `inbox/` |
| the shu seal | a human stamping `[stated]` |
| tails | confirmed lines; the self grows by the person's hand only |
| the reflection | the vault in git, the true form |
| shadow play left behind the screen | content stays; patterns travel |

The kit's rules section is binding for anything visual (README banner, landing page, favicons, future UI).
Round history is in git: round 1 (obake, greys only) is commit `9ce7a40`.
