# Agent instructions

This repo is the knowledge home of **soul.me**: concept, research, architecture and, later, the code.

## Before you work

1. Read `README.md`, then `DECISIONS.md`. Decisions there are settled unless the owner reopens them.
2. For architecture work, read `docs/architecture.md`. For context on prior art, read `docs/research.md`.
3. If an Observstory snapshot exists (Actions artifact `observstory`), read it first for in-flight work and overlaps.
   Observstory observes; it doesn't decide. If it is absent or stale, inspect the repo directly.

## Rules

- Record new decisions in `DECISIONS.md` (next D-number, date, decision, why).
- Keep it prototype-scale: no unrequested abstraction layers, config systems or frameworks.
- In any vault content, never write a line without a provenance tag, and never promote `[inferred]` to `[stated]`.
- Real personal vault data does not belong in this repo. Use fictional examples.
